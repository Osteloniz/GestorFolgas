# UI e UX

Mantenha a interface em PT-BR. O formulário público é mobile-first; o painel administrativo pode ser desktop-first. Preserve labels, navegação por teclado, foco, contraste e mensagens ligadas aos campos.

Exiba estados vazios e de carregamento úteis. Desabilite ações durante envio para evitar duplo clique. Não represente estados apenas por cor.

No conflito de última vaga, informe a data indisponível, atualize capacidade e mantenha as escolhas ainda válidas. Não exponha outros colaboradores, justificativas ou PII desnecessária.
